
PRIXO — Bundle complet (site + PWA + extension + API + médias)
==============================================================

Déploiement rapide sur Netlify
------------------------------
1) Import from Git (recommandé) ou Drag&Drop des fichiers.
2) Build command : *(vide)* — Publish directory : `.`
3) Associez le domaine `prixo.fr` dans Domain settings (suivre les DNS fournis).

Contenu
-------
- index.html, styles.css, script.js, logo_prixo.svg, favicon.svg
- Pages légales : mentions-legales.html, politique-confidentialite.html, cgu.html
- PWA : manifest.webmanifest, sw.js, /icons/*
- Scan : scan.html (démo caméra)
- Extension Chrome (MV3) : /extension/*
- API (OpenAPI) : /api/*
- Media kit : /assets/*
